Лабораторна робота №5
Варіант 3

Вимоги:
- JDK 17 або новіша версія.
- Усі файли проєкту мають знаходитися в одній папці.

Файли:
Main.java — головний клас і виконання завдань.
Employee.java — клас працівника.
StorageManager.java — узагальнений клас для зберігання об'єктів.
Department.java — клас відділу.
EmployeeDepartmentInfo.java — інформація про працівника та його відділ.
lists.txt — вхідні дані для завдання 2.
maps.txt — вхідні дані для завдання 3.

Запуск:
1. Відкрити термінал у папці проєкту.
2. Виконати команду: javac *.java
3. Запустити програму: java Main

Результат завдання 2 записується у файл result_list.txt.
